# 2. Project Lifecycle Phases

## Phase 1：项目启动 Phase

时间： T-45 \~ T-30

目标： 明确培训目标、对象和项目边界。

# 3. Risk Rule Definitions

## R001_BUDGET_DELAY

触发：

T-21 后预算仍未完成。

## R002_TRAINER_UNCONFIRMED

触发：

T-14 后讲师未确认。

## R003_VENUE_UNCONFIRMED

触发：

T-14 后场地未确认。

## R004_PARTICIPANT_NOTICE_DELAY

触发：

T-21 后学员通知未完成。

## R005_MATERIAL_DELAY

触发：

T-7 后物料仍未确认。

## R006_VENDOR_UNCLEAR

触发：

存在供应商依赖，但没有明确负责人和交付时间。

## R007_EVENT_READINESS

触发：

T-1 存在关键执行事项未关闭。

## R008_CONTENT_DELAY

触发：

培训结束后3天仍未完成宣传素材收集。

## R009_REIMBURSEMENT_DELAY

触发：

培训结束7天后报销未启动。

# 4. MVP原则

v0.1中：

-   模板由系统预置；
-   不提供复杂模板编辑；
-   用户可以在项目执行过程中补充任务；
-   AI只负责提醒和辅助判断；
-   不自动修改项目状态。
